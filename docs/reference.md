## Nodes

- `g.box`: Lays its children out in a row or a column; draws nothing itself.
- `g.capsule`: A box that draws: fill, rim, shadow, gradients, radius, blur.
- `g.text`: A text in a font, size, weight and colour; wraps or ends in an ellipsis.
- `g.icon`: An SVG icon by name (looked up in g.icon_dir) or by path, painted in `color`.
- `g.image`: A picture from a file, fitted to its box.
- `g.thread`: A quadratic Bézier with a width, grown along its length.
- `g.emitter`: Particles born at a rate, toward a heading or to a point.
- `g.shader`: A rectangle drawn by a WGSL `shade` of one's own (`src`), or a built-in effect (`src = "genoma:noise"`).
- `g.field`: A line of text to type into.
- `g.path`: Any outline: `d` (SVG path data) or `points`.
- `g.each`: A row per item, kept by key.
- `g.list`: A keyed list that scrolls, mounting only the rows in view.

Each takes the properties below; a property given a function is a binding, re-run when what it read changes.

| `drag_text` | string |  | Dragged from, it gives this text to the program it is dropped on. |
| `move_window` | boolean |  | In a g.window, pressing it moves the window, as a title bar does, and pressing it twice maximizes the window or gives back its size. A button inside it keeps its own press. |
| `combine_soft` | number | yes | How softly `combine` meets the other shape, logical units: 0 is a sharp edge; a union this soft grows a neck between shapes that come close. |

Every node also takes `role`, `name` (for assistive technology), `id` (what a popup's anchor or `combine_with` names it by) and `transition` (property → timing name).
