## Nodes

- `g.box`: Lays its children out in a row or a column; draws nothing itself.
- `g.capsule`: A box that draws: fill, rim, shadow, gradients, radius, blur.
- `g.text`: A text in a font, size, weight and colour; wraps or ends in an ellipsis.
- `g.icon`: An SVG icon by name (looked up in g.icon_dir) or by path, painted in `color`.
- `g.image`: A picture from a file, fitted to its box.
- `g.thread`: A quadratic Bézier with a width, grown along its length.
- `g.emitter`: Particles born at a rate, toward a heading or to a point.
- `g.shader`: A rectangle drawn by a WGSL `shade` of one's own (`src`), or a built-in effect (`src = "genoma:noise"`).
- `g.field`: A line of text to type into.
- `g.path`: Any outline: `d` (SVG path data) or `points`.
- `g.each`: A row per item, kept by key.
- `g.list`: A keyed list that scrolls, mounting only the rows in view.

Each takes the properties below; a property given a function is a binding, re-run when what it read changes.

| `inhibit_shortcuts` | boolean |  | While true on a catching surface, the compositor's own shortcuts stand aside and their keys reach on_key: a field recording a key combination. |
| `placeholder` | string |  | Shown in a field while it is empty. |
| `placeholder_color` | colour |  | The placeholder's colour; unset, the text's, faded. |
| `selection_color` | colour |  | What is selected in a field, drawn behind its text; unset, the text's colour at a quarter. |
| `caret_color` | colour |  | A field's caret; unset, the text's colour. |
| `focused` | boolean |  | While true, a field takes the keys and shows its caret: typing, the editing keys, Ctrl+A/C/X/V/Z/Y. Return reaches on_submit; Escape, Tab, Up and Down go on to on_key. |
| `secret` | boolean |  | A field drawn as a dot a character, and never copied out: a password. |
| `overlay` | boolean |  | Out of the parent's flow: laid over its siblings at the parent's alignment. |
| `d` | string |  | A path's outline as SVG path data (M, L, C, Q, A, Z…), in logical units from the node's top-left corner. |
| `points` | { number } |  | A path's polygon, closed: x and y of each corner in turn, logical units from the node's top-left corner. Used when `d` is not given. |
| `join` | "miter" \| "round" \| "bevel" |  | How a path's outline turns its corners. |
| `cap` | "butt" \| "round" \| "square" |  | How a path's open ends and dashes end. |
| `even_odd` | boolean |  | A path filled by the even-odd rule: where it crosses itself, a hole. |
| `combine_with` | string |  | A capsule drawn as one shape with the capsule of this id, as `combine` says: metaballs, a bite out of a shape, a lens. Name one earlier in the tree, or the shape follows it a frame late. |
| `combine` | "union" \| "subtract" \| "intersect" |  | How a capsule with `combine_with` meets the other: joined to it (both drawn, in this one's fill), with the other cut out, or only where both are. The other lends only its outline; give it no fill of its own unless it should be drawn too. |
| `blur_radius` | number | yes | The node and everything in it drawn blurred, after depth has turned it: the Gaussian's spread, logical units, as CSS's blur(). 0 (the default) costs nothing; a radius at rest is blurred once and kept, a moving one each frame. |
| `backdrop_blur` | number | yes | What this surface drew under the node, blurred this much (logical units, as CSS's backdrop-filter: blur()), shows through it inside its shape: frosted glass in the shell, whatever the compositor offers. A flat node's; 0 (the default) costs nothing, and a blur at rest is kept. Windows of other programs are the compositor's (`blur`). |
| `backdrop` | boolean |  | A shader that reads what its surface drew under it: g_backdrop(p) in its WGSL, a little beyond its edges too, for glass that bends what is behind it. Drawn again only when what is under changes. |
| `navigate` | boolean |  | Inside it the keyboard walks, once its surface has the keys: Tab and Shift+Tab, or the arrows, move the focus among its buttons and sliders, shown by a ring; a focused slider takes Left and Right; Return and space press the focused node; a row of a g.list it reaches is scrolled into view. Other keys go to the focused node and on up to its ancestors' on_key. |
| `focus_color` | colour |  | The ring round the focused node inside a `navigate` node. |
| `move_window` | boolean |  | In a g.window, pressing it moves the window, as a title bar does, and pressing it twice maximizes the window or gives back its size. A button inside it keeps its own press. |
| `combine_soft` | number | yes | How softly `combine` meets the other shape, logical units: 0 is a sharp edge; a union this soft grows a neck between shapes that come close. |

Every node also takes `role`, `name` (for assistive technology), `id` (what a popup's anchor or `combine_with` names it by) and `transition` (property → timing name).

## Input

- `on_click`: `(button: number, x: number, y: number) -> ()`
- `on_press`: `(button: number, x: number, y: number) -> ()`
- `on_release`: `(button: number, x: number, y: number) -> ()`
- `on_drag`: `(dx: number, dy: number) -> ()`
- `on_move`: `(x: number, y: number) -> ()`
- `on_hover`: `(entered: boolean) -> ()`
- `on_wheel`: `(dx: number, dy: number, steps: boolean) -> ()`
- `on_fling`: `(vx: number, vy: number) -> ()`
- `on_outside`: `() -> ()`
- `on_key`: `(name: string, text: string?, mods: { ctrl: boolean, shift: boolean, alt: boolean, logo: boolean, code: number }) -> ()`
- `on_ready`: `() -> ()`
- `on_size`: `(width: number, height: number) -> ()`
- `on_focus`: `(focused: boolean) -> ()`
- `on_focus_within`: `(x: number, y: number, width: number, height: number) -> ()`
- `on_change`: `(text: string) -> ()`
- `on_submit`: `(text: string) -> ()`
